# v0.2.0 Implementation Spec - Quick Reference

## 1. HNSW Config
```typescript
interface HNSWConfig {
  m: number;                // Default 16
  efConstruction: number;   // Default 200
  ef: number;              // Default 100
}
```

## 2. Qdrant Adapter
```typescript
new QdrantAdapter({
  url: "http://localhost:6333",
  collectionName: "vectors",
  apiKey: "optional-key"
})
```

## 3. SearchAdapter Interface
All adapters implement: index, denseSearch, keywordSearch, delete, health

## 4. Query Optimizer
- Clean: normalize input
- Expand: add synonyms
- Negate: extract "NOT X"
- Intent: detect type
- Fields: extract hints

## 5. Factory Pattern
```typescript
createAdapter({ type: 'pgvector' || 'qdrant', ... })
```

## 6. No Breaking Changes
- v0.1.0 configs still work
- IVFFlat deprecated, not removed
- API unchanged
