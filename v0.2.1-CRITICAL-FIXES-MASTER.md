### 3. ❌ Adapter Implementations Don't Match SearchAdapter Contract

**Official Contract** (`packages/contracts/src/search-adapter.ts`):
```typescript
interface DenseSearchRequest {
  queryVector: number[];    // ← REQUIRED
  entityType: string;       // ← REQUIRED
  topK: number;            // ← REQUIRED
  threshold?: number;
  distanceMetric?: 'cosine' | 'dot' | 'euclidean';
  fieldFilters?: Record<string, unknown>;
  tenantId?: string;
  principalId?: string;
}

interface IndexRequest {
  id: string;
  entityType: string;        // ← REQUIRED
  entityId: string;          // ← REQUIRED
  field: string;            // ← REQUIRED
  text: string;             // ← REQUIRED
  vector: number[];
  contentHash: string;       // ← REQUIRED
  embeddingModel: string;    // ← REQUIRED
  embeddingVersion: string;  // ← REQUIRED
  distanceMetric: 'cosine' | 'dot' | 'euclidean';  // ← REQUIRED
  dimensions: number;        // ← REQUIRED
  metadata?: Record<string, unknown>;
  weight?: number;
  retrievalStrategies?: ('semantic' | 'keyword' | 'exact')[];
  createdAt?: Date;
  updatedAt?: Date;
}
```

**Actual Implementations Use**:
```typescript
// PostgreSQL, Qdrant, Weaviate, Milvus all do:
adapter.denseSearch({
  query: embedding,          // ← WRONG (should be queryVector)
  limit: 10                 // ← WRONG (should be topK)
})

adapter.index({
  id: 'doc-1',
  vector: embedding,
  metadata: { title: '...' } // ← MISSING: entityType, entityId, field, text, etc.
})
```

**Contract Violations**:

| Interface | Contract Field | Implementation | Status |
|-----------|---------------|---|--------|
| DenseSearchRequest | queryVector | query | ❌ WRONG |
| DenseSearchRequest | topK | limit | ❌ WRONG |
| IndexRequest | entityType | missing | ❌ MISSING |
| IndexRequest | entityId | missing | ❌ MISSING |
| IndexRequest | field | missing | ❌ MISSING |
| IndexRequest | text | missing | ❌ MISSING |
| IndexRequest | contentHash | missing | ❌ MISSING |
| IndexRequest | embeddingModel | missing | ❌ MISSING |
| IndexRequest | embeddingVersion | missing | ❌ MISSING |
| IndexRequest | distanceMetric | missing | ❌ MISSING |
| IndexRequest | dimensions | missing | ❌ MISSING |
| IndexResult | success | indexed | ❌ WRONG |
| BatchIndexRequest | vectors | documents | ❌ WRONG |
| HealthStatus | latencyMs | latency | ❌ WRONG |
| AdapterStats | totalVectors | totalDocuments | ❌ WRONG |
| getVersion() | return: string | return: Promise<string> | ❌ WRONG |
| getBackendType() | return: union | return: string | ❌ WRONG |

**Compile-Time Reality**: Code that follows examples will NOT type-check against actual contract.
