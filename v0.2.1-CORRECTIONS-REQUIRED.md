### 3. ❌ hybridSearch() Breaks "One Interface" Promise

**Issue**: Weaviate example calls `hybridSearch()` which is not in SearchAdapter interface

**Problem**: Code using hybridSearch() is not portable to other adapters

**Current**:
```typescript
// This only works on Weaviate!
adapter.hybridSearch({
  query: 'machine learning',
  vector: embedding,
  alpha: 0.5,
  limit: 10,
});

// What about other adapters?
```

**Solution**: Capability Detection

```typescript
interface AdapterCapabilities {
  dense: boolean;
  keyword: boolean;
  hybrid: boolean;
  nativeExplain: boolean;
  multiTenant: boolean;
  transactions: boolean;
  filtering: boolean;
  partitioning: boolean;
  clustering: boolean;
}

// Usage
const caps = await adapter.getCapabilities();
if (caps.hybrid) {
  // Use native hybrid
  return await (adapter as HybridSearchCapable).hybridSearch(request);
} else {
  // Use SDK-level RRF
  return sdk.fuseDenseAndKeyword(
    await adapter.denseSearch(...),
    await adapter.keywordSearch(...)
  );
}
```

**Files to Update**:
- [ ] `packages/contracts/src/search-adapter.ts` - Add `getCapabilities()`
- [ ] `packages/contracts/src/adapter-capabilities.ts` - New file
- [ ] All adapter implementations - implement `getCapabilities()`
- [ ] Examples - show capability checking

**Status**: 🟠 PARTIALLY CORRECTED - interface defined, needs implementation
